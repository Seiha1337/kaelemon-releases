# Kaelemon Launcher

Le launcher du serveur Minecraft Pokémon **Kaelemon** : son installeur (`Kaelemon-Setup-<version>.exe`) et ses mises à jour sont dans les **[releases](https://github.com/Seiha1337/kaelemon-releases/releases/latest)** (toujours la dernière version en haut).

- **Pour jouer**, passe par le site : **[kaelemon.seiha.dev](https://kaelemon.seiha.dev)**.
- **Les mises à jour** se font toutes seules : le launcher installé vérifie les nouvelles versions ici et se met à jour de lui-même.

Il faut Windows 10 ou 11 (64 bits) et Minecraft Java Edition sur ton compte Microsoft. Au premier lancement, Windows peut afficher « Windows a protégé votre ordinateur » (le launcher n'est pas encore signé) : *Informations complémentaires*, puis *Exécuter quand même*.
