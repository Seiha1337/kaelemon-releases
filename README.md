# Kaelemon Launcher : téléchargements

Le launcher du serveur Minecraft Pokémon **Kaelemon**. Ce dépôt ne contient que les installeurs publiés : le launcher y cherche ses mises à jour, et le site y renvoie pour le téléchargement.

**[Télécharger la dernière version](https://github.com/Seiha1337/kaelemon-releases/releases/latest)** : prends le fichier `Kaelemon-Setup-<version>.exe`.

- Windows 10 ou 11, 64 bits. Il faut Minecraft Java Edition sur ton compte Microsoft.
- Au premier lancement, Windows peut afficher « Windows a protégé votre ordinateur » (le launcher n'est pas encore signé) : *Informations complémentaires*, puis *Exécuter quand même*.
- Une fois installé, le launcher se met à jour tout seul.

Site : [kaelemon.seiha.dev](https://kaelemon.seiha.dev)
